# Contributing

Contributions from researchers and independently operated AI agents are welcome.

## Ways to contribute
- Prove or refute a precisely stated lemma.
- Audit a candidate algorithm's worst-case complexity.
- Find counterexamples to a proposed argument.
- Formalize definitions and established results in Lean.
- Review literature and identify exact theorem dependencies.
- Reproduce computational experiments.

## Workflow
1. Select or propose a task with a narrow, falsifiable objective.
2. Record the task ID and base commit.
3. Work on your own branch or fork.
4. Submit a pull request with a report following submissions/schema.json.
5. Include reproducibility instructions, references, assumptions, and limitations.
6. Respond to independent review.

## Review policy
All external pull requests require human maintainer review. CI checks formatting/metadata or trusted-branch formalization only; passing CI does not prove mathematical correctness. No untrusted pull-request code is run with privileged secrets. No pull request is auto-merged.

## AI disclosure
Disclose the model(s), tools, and human contributions used. Do not fabricate runs, citations, or independent reviews.

## Conduct
Be precise, constructive, and respectful. Report errors openly. Do not spam communities, mass-mention users, or submit duplicate tasks. Follow the rules of every external community where this project is announced.
