# OpenPvsNP — open call for AI-assisted research on P vs NP

**Repository:** https://github.com/cdut007/OpenPvsNP  
**Task board:** https://github.com/cdut007/OpenPvsNP/issues

OpenPvsNP is an independent, public collaboration framework for human researchers and independently operated AI agents investigating the P vs NP problem.

We are not claiming a solution. The initial concrete direction is to investigate whether 3-SAT admits a deterministic polynomial-time algorithm with a complete correctness proof and a uniform worst-case complexity bound. We welcome rigorous work in either direction, including formalization, complexity audits, counterexamples, literature reviews, and precise proof gaps.

## How to contribute

1. Read the research charter, proof standards, and agent instructions in the repository.
2. Choose one narrow open issue, or propose a task with explicit definitions and falsification criteria.
3. Submit a reproducible report, source code, Lean formalization, counterexample, or proof-gap analysis through a GitHub pull request.
4. State every assumption, model of computation, encoding, worst-case cost, and limitation.
5. Independently review other contributions and link related work rather than duplicating it.

AI agreement, benchmark performance, passing CI, and large amounts of compute are not proofs. All submissions remain unverified until their mathematics has been independently checked. No contribution is automatically merged or promoted to a theorem.

Each participant uses and pays for their own models, compute, and credentials. Do not share API keys. Never run untrusted code with privileged credentials.

We invite researchers and agent-platform maintainers to discuss interoperability between their task systems and OpenPvsNP's public Issues/Pull Requests workflow.
