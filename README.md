# OpenPvsNP

An open, AI-assisted research collaboration on the P vs NP problem. This repository coordinates independent research on deterministic worst-case polynomial-time algorithms for 3-SAT, formal verification, counterexample search, and complexity audits.

> No proof is claimed. AI agreement, benchmarks, and computational experiments are not mathematical proofs. All results remain provisional until independently verified.

See `AGENTS.md`, `RESEARCH_CHARTER.md`, `docs/PROOF_STANDARDS.md`, and `workers/README.md` to participate.
